# team7

익명 SNS 질문 완주·안전·친구 네트워크 분석

익명 SNS의 질문 내용·질문 순서·사용자 특성·친구 네트워크가  
10문항 완주율과 스킵·신고 행동에 미치는 관계를 분석하는 프로젝트입니다.

## 프로젝트 주제

> 질문의 재미와 안전, 친구 네트워크가 익명 SNS의 10문항 완주를 만드는 조건

어떤 질문을 어떤 사용자 관계망에 어떤 순서로 보여줘야 완주율을 높이고  
스킵과 신고를 줄일 수 있는지 분석합니다.

## 프로젝트 기간

- 분석 기간: 2026년 8월 31일 ~ 2026년 10월 2일
- 데이터 기간: 2023년 7월 18일 ~ 2023년 8월 10일
- 최종 발표: 2026년 10월 2일

## 주요 분석 범위

- 질문 시작 → 스킵 → 완료 퍼널 분석
- 질문 내용과 유형별 참여 성과 분석
- 질문 순서와 연속 노출에 따른 피로도 분석
- 질문별 신고 및 안전성 분석
- 친구 수와 네트워크 특성에 따른 행동 차이 분석
- 질문 경험 이후 재방문·Ping 열람 등 후속 행동 분석

# 팀 협업 규칙

## 브랜치 전략

본 프로젝트는 `main` 브랜치를 기준으로 작업별 브랜치를 생성하는 방식으로 진행합니다.

- `main` 브랜치에는 직접 커밋하거나 Push하지 않습니다.
- 작업을 시작하기 전에 `main` 브랜치의 최신 내용을 Pull합니다.
- 담당 작업별로 새로운 브랜치를 생성합니다.
- 하나의 브랜치에서는 하나의 분석 목적만 수행합니다.
- 작업이 완료되면 GitHub에 Push하고 Pull Request를 생성합니다.
- 최소 1명의 팀원이 코드를 검토한 후 `main` 브랜치에 병합합니다.
- 병합이 완료된 작업 브랜치는 삭제합니다.

### 작업 흐름
main 최신화
    ↓
작업 브랜치 생성
    ↓
SQL·Python·문서 작업
    ↓
Commit 및 Push
    ↓
Pull Request 생성
    ↓
팀원 코드 리뷰
    ↓
main 병합


### 브랜치 타입

| 브랜치 타입 | 설명 |
|---|---|
| `feat` | 새로운 기능, 분석 또는 데이터 마트 추가 |
| `fix` | 코드 및 데이터 처리 오류 수정 |
| `docs` | README, 데이터 명세서 등 문서 작성 및 수정 |

### 브랜치 이름 형식

feat-브랜치명#이슈번호
feat-question-attempt-mart#1

### 커밋 컨벤션
[Feat] 질문 진행 시도 마트 생성
[Feat] 질문 순서별 스킵률 분석 추가
[Fix] 중복 완료 이벤트 집계 오류 수정
[Docs] 프로젝트 README 작성
